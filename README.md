# سوالف الأولين — Salef Al-Awaleen

تجربة حوار قصصي عربي على Meta Quest، باستخدام Godot 4 وOpenXR. هذه نسخة تجريبية وظيفية، ولم يُختبر APK بعد على النظارة.

## التشغيل
1. افتح Actions > Build Quest APK > Run workflow.
2. حمّل artifact باسم salef-quest-debug وثبّت APK على Quest 3.
3. للاستفادة من الذكاء الاصطناعي أدخل عنوان خادم المحادثة في واجهة التطبيق. الخادم يجب أن يقدّم مسار POST /chat ويستقبل JSON بصيغة {"message":"...","history":[]} ويعيد {"reply":"..."}.
4. النموذج الأولي يختبر النص أولاً؛ الصوت في المرحلة التالية. لا تضع مفاتيح OpenAI في التطبيق أو المستودع.

**حدود الإصدار:** شخصية ومجلس برمجيان، واجهة نصية، واختبار إرسال المحادثة إلى خادم خارجي. لا يوجد حتى الآن تسجيل صوت عربي أو نطق صوتي أو تحريك فم.
